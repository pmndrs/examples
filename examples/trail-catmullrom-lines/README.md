# Trail & CatmullRom Lines

Interactive ribbon light trails following floating animated meshes along 3D CatmullRom spline curves with configurable line tension, decay, and float dynamics.

Showcases:

- `@react-three/drei`: `<Trail>`, `<CatmullRomLine>`, `<Float>`, `<OrbitControls>`
- `@react-three/fiber`: Canvas, `useFrame`
- `leva`: interactive controls
